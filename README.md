# 🌍 Overview

VESA OS is an AI-powered operating system built specifically for creative agencies, digital studios, startups, freelancers, and organizations that manage client projects.

Instead of switching between:

- WhatsApp
- Google Drive
- Gmail
- Notion
- Trello
- ClickUp
- Slack
- Excel Sheets
- Figma comments

VESA OS centralizes everything into one intelligent workspace.

It combines project management, client collaboration, AI assistance, file management, meetings, approvals, revisions, and analytics into one seamless platform.

# 🚀 Local Development

Clone

```bash
git clone https://github.com/vedant-B22/Vesa-OS.git
```

Install

```bash
npm install
```

Development

```bash
npm run dev
```

Production Build

```bash
npm run build
```

Push Database

```bash
npx prisma db push
```

Prisma Studio

```bash
npx prisma studio
```

Seed Admin

```bash
npx tsx seed-admin.ts
```
